## 最初の3ステップ

1. [最新リリース](https://github.com/hjosugi/ayame-editor/releases/latest)から OS に合うビルドを取得します。
2. [ユーザーガイド](USER_GUIDE.md)に沿ってファイルを開き、文字コードを確認します。
3. 繰り返し処理は [CLI リファレンス](CLI_REFERENCE.md)から目的のコマンドを探します。
